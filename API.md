Инструкция для разработчика

## Назначение API

REST API платформы «Vzаимопомощь» (College Bank) предназначен для управления публикациями студентов — запросами о помощи и предложениями помощи. API позволяет получать список публикаций, получать одну публикацию, создавать, обновлять и удалять публикации. Данные передаются в формате JSON в кодировке UTF-8. Базовый адрес API: http://127.0.0.1:8000/api/offers.php

## Как запустить проект

Проект работает на PHP и SQLite. Запуск сервера из корня проекта:

    php -S 127.0.0.1:8000 -t public

После запуска API доступен по адресу http://127.0.0.1:8000/api/offers.php.

## Как получить список публикаций

Метод GET по адресу /api/offers.php. Необязательные параметры: type (offer или request), page (номер страницы), limit (количество записей).

Успешный ответ с кодом 200 содержит массив публикаций с полями id, user_id, category_id, title, description, contact_link, status, type, created_at, author_name, category_name. Неверный type возвращает код 400.

## Как получить одну публикацию

Метод GET по адресу /api/offers.php?id=5. Успешный ответ с кодом 200 содержит объект публикации. Некорректный id возвращает код 400, отсутствующая публикация возвращает код 404.

## Как отправить POST-запрос

Метод POST по адресу /api/offers.php с заголовком Content-Type: application/json. API принимает поля title (string, до 200 символов), description (string, до 5000 символов), user_id (integer), type (offer или request). Все поля обязательны.

Пример JSON:

    {
      "title": "Помощь с базами данных",
      "description": "Помогу разобраться с SQL",
      "user_id": 2,
      "type": "offer"
    }

## Какие ответы может вернуть сервер

200 — успешный GET-запрос.

201 — успешный POST-запрос.

400 — неверный Content-Type, некорректный JSON, ошибка валидации, неверный type или некорректный id.

404 — публикация не найдена.

405 — неподдерживаемый HTTP-метод.

500 — внутренняя ошибка сервера или базы данных.

## Какие ошибки могут возникнуть

400 — отсутствует заголовок Content-Type: application/json.

400 — тело запроса содержит некорректный JSON.

400 — не передан user_id при создании публикации.

400 — поле type не входит в список offer и request.

400 — поле title пустое или длиннее 200 символов.

400 — поле description длиннее 5000 символов.

400 — идентификатор id меньше или равен нулю.

404 — публикация с указанным id не существует.

405 — используется неподдерживаемый HTTP-метод.
